# Marketing metrics

The platform includes reusable formulas for acquisition, conversion, and revenue metrics with safe handling for zero, null, and missing values.

## Core formulas

- CTR = Clicks / Impressions × 100
- CPC = Spend / Clicks
- Conversion Rate = Conversions / Clicks × 100
- CAC = Spend / Conversions
- AOV = Revenue / Conversions
- ROAS = Attributed Revenue / Spend
- ROI = (Attributed Revenue - Spend) / Spend × 100

Every metric will be calculated with divide-by-zero protection and explicit handling for missing values.
